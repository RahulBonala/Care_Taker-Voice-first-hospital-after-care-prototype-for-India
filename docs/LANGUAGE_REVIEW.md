# Language review sheet

Generated by `npm run review-sheet` from `server/lang/*.json`. Do not edit this file by hand: fix the language file and run the script again.

## For the reviewer

Thank you for checking a language. Read each line in the "Current text" column next to the English, then tick the last column.

Check each line for:

1. **Natural wording.** It should sound like a polite hospital staff member speaking to an older patient, not a word-by-word translation.
2. **Politeness.** Use the respectful form of "you" that a patient would expect from a hospital.
3. **No medical advice.** A line states facts only. It never tells the patient to eat, walk, rest, take or change a medicine. Anything outside a range says a nurse or the care team will look at it.
4. **Placeholders kept.** Words in curly brackets, such as `{name}`, `{slot}`, `{time}` or `{steps}`, are filled in by the app. Keep them exactly as written, in any position that reads naturally. Numbers stay as digits.
5. **Short.** Call lines stay under 15 words. No long dash characters: use a comma, colon or full stop.

How to mark a line:

- Put `yes` in the OK? column if the line is right.
- If it is wrong, write the better wording in the OK? column, or send it to the team with the key name.

When every line in a language is ticked, open `server/lang/<code>.json` and set `"reviewedByNativeSpeaker": true`. The app then stops showing the "Language under review" tag for that language.
