# Kannada fallback clips

Used when the browser has no kn-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | ನಮಸ್ಕಾರ {name} ಅವರೇ. ನಾನು ನಿಮ್ಮ ಆಸ್ಪತ್ರೆಯಿಂದ ಕೇರ್ ಟೇಕರ್ ಮಾತನಾಡುತ್ತಿದ್ದೇನೆ. |
| `askTaken` | ನೀವು ಊಟ ಮಾಡಿದಿರಾ? ನಿಮ್ಮ {slot} ಮಾತ್ರೆಗಳನ್ನು ತೆಗೆದುಕೊಂಡಿರಾ? |
| `progress` | ಇಂದು ನಿಮ್ಮ {total} ದಿನಗಳ ಕೋರ್ಸ್‌ನ {n}ನೇ ದಿನ. ಕೋರ್ಸ್ ಪೂರ್ಣಗೊಳಿಸಲು ವೈದ್ಯರು ಹೇಳಿದ್ದಾರೆ. |
| `readback` | ನೀವು {time}ಕ್ಕೆ ನಿಮ್ಮ {slot} ಮಾತ್ರೆಗಳನ್ನು ತೆಗೆದುಕೊಂಡಿದ್ದೀರಿ. ಸರಿಯೇ? ಹೌದು ಎನ್ನಿ ಅಥವಾ 1 ಒತ್ತಿ. |
| `confirmed` | ಧನ್ಯವಾದಗಳು. ನಾನು ಬರೆದುಕೊಂಡಿದ್ದೇನೆ. |
| `askAgain` | ಕ್ಷಮಿಸಿ. ಮತ್ತೊಮ್ಮೆ ಹೇಳಿ. ನಿಮ್ಮ {slot} ಮಾತ್ರೆಗಳನ್ನು ತೆಗೆದುಕೊಂಡಿರಾ? |
| `notTakenOffer` | ಈಗ ತೆಗೆದುಕೊಳ್ಳುತ್ತೀರಾ? ನಾನು 30 ನಿಮಿಷಗಳ ನಂತರ ಮತ್ತೆ ಕರೆ ಮಾಡಬಹುದು. |
| `takeNow` | ದಯವಿಟ್ಟು ಈಗಲೇ ತೆಗೆದುಕೊಳ್ಳಿ. ನಾನು {minutes} ನಿಮಿಷಗಳ ನಂತರ ಕರೆ ಮಾಡುತ್ತೇನೆ. |
| `postponeOk` | ಸರಿ. ನಾನು {minutes} ನಿಮಿಷಗಳ ನಂತರ ಮತ್ತೆ ಕರೆ ಮಾಡುತ್ತೇನೆ. |
| `postponeLimit` | ಈ ಡೋಸ್ ಮೂರು ಬಾರಿ ಮುಂದೂಡಲಾಗಿದೆ. ನಿಮ್ಮ ಆರೈಕೆ ತಂಡಕ್ಕೆ ತಿಳಿಸುತ್ತಿದ್ದೇನೆ. |
| `nurseComing` | ಕೆಲವೇ ನಿಮಿಷಗಳಲ್ಲಿ ಒಬ್ಬ ನರ್ಸ್ ನಿಮಗೆ ಕರೆ ಮಾಡುತ್ತಾರೆ. |
| `askWhyStopped` | ನೀವು ಯಾಕೆ ನಿಲ್ಲಿಸಿದಿರಿ ಎಂದು ಹೇಳಬಹುದೇ? |
| `tellingTeam` | ಧನ್ಯವಾದಗಳು. ನಿಮ್ಮ ಆರೈಕೆ ತಂಡಕ್ಕೆ ತಿಳಿಸುತ್ತಿದ್ದೇನೆ. |
| `askCallbackWhen` | ನಾನು ಯಾವಾಗ ಮತ್ತೆ ಕರೆ ಮಾಡಲಿ? |
| `unclear` | ಕ್ಷಮಿಸಿ, ಸರಿಯಾಗಿ ಕೇಳಿಸಲಿಲ್ಲ. ನಿಮ್ಮ {slot} ಮಾತ್ರೆಗಳನ್ನು ತೆಗೆದುಕೊಂಡಿರಾ? |
| `keypad` | ದಯವಿಟ್ಟು ಕೀಪ್ಯಾಡ್ ಬಳಸಿ. ತೆಗೆದುಕೊಂಡಿದ್ದರೆ 1. ನಂತರ ಕರೆಗೆ 2. ನರ್ಸ್‌ಗೆ 3. |
| `noKey` | ನನಗೆ ಉತ್ತರ ಸಿಗಲಿಲ್ಲ. ನಿಮ್ಮ ಆರೈಕೆ ತಂಡಕ್ಕೆ ತಿಳಿಸುತ್ತಿದ್ದೇನೆ. |
| `goodbye` | ಆರೋಗ್ಯದಿಂದಿರಿ. ನಾನು {time}ಕ್ಕೆ ಮತ್ತೆ ಕರೆ ಮಾಡುತ್ತೇನೆ. |
| `goodbyeDone` | ಆರೋಗ್ಯದಿಂದಿರಿ. ಇದು ನಿಮ್ಮ ಕೋರ್ಸ್‌ನ ಕೊನೆಯ ಡೋಸ್. |
| `optOut` | ಸರಿ. ನಾನು ಕರೆಗಳನ್ನು ನಿಲ್ಲಿಸುತ್ತೇನೆ. ನಿಮ್ಮ ಆರೈಕೆ ತಂಡಕ್ಕೆ ತಿಳಿಸಲಾಗುವುದು. |
