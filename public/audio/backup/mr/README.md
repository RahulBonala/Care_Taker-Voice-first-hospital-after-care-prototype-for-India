# Marathi fallback clips

Used when the browser has no mr-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | नमस्कार {name}. मी तुमच्या रुग्णालयातून केअर टेकर बोलत आहे. |
| `askTaken` | तुम्ही जेवलात का? तुमच्या {slot} गोळ्या घेतल्या का? |
| `progress` | आज तुमच्या {total} दिवसांच्या कोर्सचा {n}वा दिवस आहे. डॉक्टरांनी कोर्स पूर्ण करायला सांगितले आहे. |
| `readback` | तुम्ही {time} वाजता तुमच्या {slot} गोळ्या घेतल्या. बरोबर आहे का? हो म्हणा किंवा 1 दाबा. |
| `confirmed` | धन्यवाद. मी लिहून घेतले आहे. |
| `askAgain` | माफ करा. पुन्हा सांगा. तुमच्या {slot} गोळ्या घेतल्या का? |
| `notTakenOffer` | आता घ्याल का? मी 30 मिनिटांनी पुन्हा फोन करू शकतो. |
| `takeNow` | कृपया आताच घ्या. मी {minutes} मिनिटांनी फोन करेन. |
| `postponeOk` | ठीक आहे. मी {minutes} मिनिटांनी पुन्हा फोन करेन. |
| `postponeLimit` | हा डोस तीन वेळा पुढे ढकलला आहे. मी तुमच्या काळजी टीमला सांगत आहे. |
| `nurseComing` | काही मिनिटांत एक नर्स तुम्हाला फोन करेल. |
| `askWhyStopped` | तुम्ही का थांबवले ते सांगाल का? |
| `tellingTeam` | धन्यवाद. मी तुमच्या काळजी टीमला सांगत आहे. |
| `askCallbackWhen` | मी पुन्हा कधी फोन करू? |
| `unclear` | माफ करा, नीट ऐकू आले नाही. तुमच्या {slot} गोळ्या घेतल्या का? |
| `keypad` | कृपया कीपॅड वापरा. घेतल्या असतील तर 1. नंतर फोनसाठी 2. नर्ससाठी 3. |
| `noKey` | मला उत्तर मिळाले नाही. मी तुमच्या काळजी टीमला सांगत आहे. |
| `goodbye` | काळजी घ्या. मी {time} वाजता पुन्हा फोन करेन. |
| `goodbyeDone` | काळजी घ्या. हा तुमच्या कोर्सचा शेवटचा डोस होता. |
| `optOut` | ठीक आहे. मी फोन बंद करतो. तुमच्या काळजी टीमला कळवले जाईल. |
