# Bengali fallback clips

Used when the browser has no bn-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | নমস্কার {name}। আমি আপনার হাসপাতাল থেকে কেয়ার টেকার বলছি। |
| `askTaken` | আপনি কি খেয়েছেন? আপনার {slot} ওষুধ খেয়েছেন? |
| `progress` | আজ আপনার {total} দিনের কোর্সের {n} নম্বর দিন। ডাক্তার কোর্স শেষ করতে বলেছেন। |
| `readback` | আপনি {time}টায় আপনার {slot} ওষুধ খেয়েছেন। ঠিক তো? হ্যাঁ বলুন বা 1 টিপুন। |
| `confirmed` | ধন্যবাদ। আমি লিখে রাখলাম। |
| `askAgain` | দুঃখিত। আবার বলুন। আপনার {slot} ওষুধ খেয়েছেন? |
| `notTakenOffer` | এখন খাবেন? আমি 30 মিনিট পরে আবার ফোন করতে পারি। |
| `takeNow` | দয়া করে এখনই খেয়ে নিন। আমি {minutes} মিনিট পরে ফোন করব। |
| `postponeOk` | ঠিক আছে। আমি {minutes} মিনিট পরে আবার ফোন করব। |
| `postponeLimit` | এই ডোজ তিনবার পিছিয়েছে। আপনার চিকিৎসা দলকে জানাচ্ছি। |
| `nurseComing` | কয়েক মিনিটের মধ্যে একজন নার্স আপনাকে ফোন করবেন। |
| `askWhyStopped` | কেন বন্ধ করলেন, বলবেন? |
| `tellingTeam` | ধন্যবাদ। আপনার চিকিৎসা দলকে জানাচ্ছি। |
| `askCallbackWhen` | আমি কখন আবার ফোন করব? |
| `unclear` | দুঃখিত, ঠিক শুনতে পাইনি। আপনার {slot} ওষুধ খেয়েছেন? |
| `keypad` | দয়া করে কীপ্যাড ব্যবহার করুন। খেয়ে থাকলে 1। পরে ফোনের জন্য 2। নার্সের জন্য 3। |
| `noKey` | আমি উত্তর পাইনি। আপনার চিকিৎসা দলকে জানাচ্ছি। |
| `goodbye` | ভালো থাকবেন। আমি {time}টায় আবার ফোন করব। |
| `goodbyeDone` | ভালো থাকবেন। এটাই আপনার কোর্সের শেষ ডোজ। |
| `optOut` | ঠিক আছে। আমি ফোন বন্ধ করছি। আপনার চিকিৎসা দলকে জানানো হবে। |
