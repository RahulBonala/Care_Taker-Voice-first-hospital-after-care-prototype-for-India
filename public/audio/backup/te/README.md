# Telugu fallback clips

Used when the browser has no te-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | నమస్కారం {name} గారు. నేను మీ ఆసుపత్రి నుండి కేర్ టేకర్ మాట్లాడుతున్నాను. |
| `askTaken` | మీరు భోజనం చేశారా? మీ {slot} మాత్రలు వేసుకున్నారా? |
| `progress` | ఈ రోజు మీ కోర్సులో {total} రోజులలో {n}వ రోజు. కోర్సు పూర్తి చేయమని మీ డాక్టర్ చెప్పారు. |
| `readback` | మీరు {time}కి మీ {slot} మాత్రలు వేసుకున్నారు. సరేనా? అవును అని చెప్పండి లేదా 1 నొక్కండి. |
| `confirmed` | ధన్యవాదాలు. నేను రాసుకున్నాను. |
| `askAgain` | క్షమించండి. మళ్ళీ చెప్పండి. మీ {slot} మాత్రలు వేసుకున్నారా? |
| `notTakenOffer` | ఇప్పుడు వేసుకుంటారా? నేను 30 నిమిషాల తర్వాత మళ్ళీ కాల్ చేయగలను. |
| `takeNow` | దయచేసి ఇప్పుడే వేసుకోండి. నేను {minutes} నిమిషాల తర్వాత మళ్ళీ కాల్ చేస్తాను. |
| `postponeOk` | సరే. నేను {minutes} నిమిషాల తర్వాత మళ్ళీ కాల్ చేస్తాను. |
| `postponeLimit` | ఈ మోతాదును మూడు సార్లు వాయిదా వేశాము. మీ సంరక్షణ బృందానికి చెబుతున్నాను. |
| `nurseComing` | కొన్ని నిమిషాల్లో ఒక నర్సు మీకు కాల్ చేస్తారు. |
| `askWhyStopped` | మీరు ఎందుకు ఆపేశారో చెప్పగలరా? |
| `tellingTeam` | ధన్యవాదాలు. మీ సంరక్షణ బృందానికి చెబుతున్నాను. |
| `askCallbackWhen` | నేను ఎప్పుడు మళ్ళీ కాల్ చేయాలి? |
| `unclear` | క్షమించండి, నాకు సరిగ్గా వినపడలేదు. మీ {slot} మాత్రలు వేసుకున్నారా? |
| `keypad` | దయచేసి కీప్యాడ్ వాడండి. వేసుకుంటే 1 నొక్కండి. తర్వాత కాల్ కోసం 2 నొక్కండి. నర్సుతో మాట్లాడటానికి 3 నొక్కండి. |
| `noKey` | నాకు సమాధానం రాలేదు. మీ సంరక్షణ బృందానికి చెబుతున్నాను. |
| `goodbye` | జాగ్రత్తగా ఉండండి. నేను {time}కి మళ్ళీ కాల్ చేస్తాను. |
| `goodbyeDone` | జాగ్రత్తగా ఉండండి. ఇది మీ కోర్సులో చివరి మోతాదు. |
| `optOut` | సరే. నేను కాల్స్ ఆపేస్తాను. మీ సంరక్షణ బృందానికి చెబుతాను. |
