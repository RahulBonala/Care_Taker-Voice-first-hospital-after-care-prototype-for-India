# Hindi fallback clips

Used when the browser has no hi-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | नमस्ते {name} जी. मैं आपके अस्पताल से केयर टेकर बोल रहा हूँ. |
| `askTaken` | क्या आपने खाना खा लिया? क्या आपने अपनी {slot} दवाई ले ली? |
| `progress` | आज आपके कोर्स का {total} में से {n}वां दिन है. आपके डॉक्टर ने कोर्स पूरा करने को कहा है. |
| `readback` | आपने {time} बजे अपनी {slot} दवाई ली. क्या यह सही है? हाँ बोलिए या 1 दबाइए. |
| `confirmed` | धन्यवाद. मैंने लिख लिया है. |
| `askAgain` | माफ़ कीजिए. फिर से बताइए. क्या आपने अपनी {slot} दवाई ले ली? |
| `notTakenOffer` | क्या आप अभी ले लेंगे? मैं 30 मिनट बाद फिर से कॉल कर सकता हूँ. |
| `takeNow` | कृपया अभी ले लीजिए. मैं {minutes} मिनट बाद फिर से कॉल करूँगा. |
| `postponeOk` | ठीक है. मैं {minutes} मिनट बाद फिर से कॉल करूँगा. |
| `postponeLimit` | यह खुराक तीन बार आगे बढ़ चुकी है. मैं आपकी केयर टीम को बता रहा हूँ. |
| `nurseComing` | कुछ ही मिनटों में एक नर्स आपको कॉल करेंगी. |
| `askWhyStopped` | क्या आप बता सकते हैं कि आपने दवाई क्यों बंद की? |
| `tellingTeam` | धन्यवाद. मैं आपकी केयर टीम को बता रहा हूँ. |
| `askCallbackWhen` | मैं कब फिर से कॉल करूँ? |
| `unclear` | माफ़ कीजिए, मुझे ठीक से सुनाई नहीं दिया. क्या आपने अपनी {slot} दवाई ले ली? |
| `keypad` | कृपया कीपैड का इस्तेमाल कीजिए. दवाई ले ली हो तो 1 दबाइए. बाद में कॉल के लिए 2 दबाइए. नर्स से बात करने के लिए 3 दबाइए. |
| `noKey` | मुझे जवाब नहीं मिला. मैं आपकी केयर टीम को बता रहा हूँ. |
| `goodbye` | अपना ध्यान रखिए. मैं {time} बजे फिर से कॉल करूँगा. |
| `goodbyeDone` | अपना ध्यान रखिए. यह आपके कोर्स की आखिरी खुराक थी. |
| `optOut` | ठीक है. मैं कॉल बंद कर दूँगा. आपकी केयर टीम को बताया जाएगा. |
