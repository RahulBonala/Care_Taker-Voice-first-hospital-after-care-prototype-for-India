# Malayalam fallback clips

Used when the browser has no ml-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | നമസ്കാരം {name}. ഞാൻ നിങ്ങളുടെ ആശുപത്രിയിൽ നിന്ന് കെയർ ടേക്കർ ആണ് വിളിക്കുന്നത്. |
| `askTaken` | ഭക്ഷണം കഴിച്ചോ? നിങ്ങളുടെ {slot} ഗുളികകൾ കഴിച്ചോ? |
| `progress` | ഇന്ന് നിങ്ങളുടെ {total} ദിവസത്തെ കോഴ്സിലെ {n}ആം ദിവസം. കോഴ്സ് പൂർത്തിയാക്കാൻ ഡോക്ടർ പറഞ്ഞിട്ടുണ്ട്. |
| `readback` | നിങ്ങൾ {time}ന് {slot} ഗുളികകൾ കഴിച്ചു. ശരിയാണോ? അതെ എന്ന് പറയൂ, അല്ലെങ്കിൽ 1 അമർത്തൂ. |
| `confirmed` | നന്ദി. ഞാൻ എഴുതിവെച്ചു. |
| `askAgain` | ക്ഷമിക്കണം. ഒന്നുകൂടി പറയൂ. നിങ്ങളുടെ {slot} ഗുളികകൾ കഴിച്ചോ? |
| `notTakenOffer` | ഇപ്പോൾ കഴിക്കുമോ? 30 മിനിറ്റിന് ശേഷം ഞാൻ വീണ്ടും വിളിക്കാം. |
| `takeNow` | ദയവായി ഇപ്പോൾ കഴിക്കൂ. {minutes} മിനിറ്റിന് ശേഷം ഞാൻ വിളിക്കും. |
| `postponeOk` | ശരി. {minutes} മിനിറ്റിന് ശേഷം ഞാൻ വീണ്ടും വിളിക്കും. |
| `postponeLimit` | ഈ ഡോസ് മൂന്ന് തവണ മാറ്റിവെച്ചു. നിങ്ങളുടെ പരിചരണ സംഘത്തെ അറിയിക്കുന്നു. |
| `nurseComing` | കുറച്ച് മിനിറ്റിനുള്ളിൽ ഒരു നഴ്സ് നിങ്ങളെ വിളിക്കും. |
| `askWhyStopped` | എന്തുകൊണ്ടാണ് നിർത്തിയതെന്ന് പറയാമോ? |
| `tellingTeam` | നന്ദി. നിങ്ങളുടെ പരിചരണ സംഘത്തെ അറിയിക്കുന്നു. |
| `askCallbackWhen` | ഞാൻ എപ്പോൾ വീണ്ടും വിളിക്കണം? |
| `unclear` | ക്ഷമിക്കണം, ശരിക്ക് കേട്ടില്ല. നിങ്ങളുടെ {slot} ഗുളികകൾ കഴിച്ചോ? |
| `keypad` | ദയവായി കീപാഡ് ഉപയോഗിക്കൂ. കഴിച്ചെങ്കിൽ 1. പിന്നീട് വിളിക്കാൻ 2. നഴ്സിന് 3. |
| `noKey` | എനിക്ക് മറുപടി കിട്ടിയില്ല. നിങ്ങളുടെ പരിചരണ സംഘത്തെ അറിയിക്കുന്നു. |
| `goodbye` | ശ്രദ്ധിക്കൂ. {time}ന് ഞാൻ വീണ്ടും വിളിക്കും. |
| `goodbyeDone` | ശ്രദ്ധിക്കൂ. ഇത് നിങ്ങളുടെ കോഴ്സിലെ അവസാന ഡോസ് ആണ്. |
| `optOut` | ശരി. ഞാൻ വിളികൾ നിർത്തുന്നു. നിങ്ങളുടെ പരിചരണ സംഘത്തെ അറിയിക്കും. |
