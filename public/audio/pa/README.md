# Punjabi fallback clips

Used when the browser has no pa-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | ਸਤ ਸ੍ਰੀ ਅਕਾਲ {name} ਜੀ। ਮੈਂ ਤੁਹਾਡੇ ਹਸਪਤਾਲ ਤੋਂ ਕੇਅਰ ਟੇਕਰ ਬੋਲ ਰਿਹਾ ਹਾਂ। |
| `askTaken` | ਕੀ ਤੁਸੀਂ ਖਾਣਾ ਖਾ ਲਿਆ? ਕੀ ਤੁਸੀਂ ਆਪਣੀਆਂ {slot} ਗੋਲੀਆਂ ਲੈ ਲਈਆਂ? |
| `progress` | ਅੱਜ ਤੁਹਾਡੇ {total} ਦਿਨਾਂ ਦੇ ਕੋਰਸ ਦਾ {n}ਵਾਂ ਦਿਨ ਹੈ। ਡਾਕਟਰ ਨੇ ਕੋਰਸ ਪੂਰਾ ਕਰਨ ਲਈ ਕਿਹਾ ਹੈ। |
| `readback` | ਤੁਸੀਂ {time} ਵਜੇ ਆਪਣੀਆਂ {slot} ਗੋਲੀਆਂ ਲਈਆਂ। ਕੀ ਇਹ ਠੀਕ ਹੈ? ਹਾਂ ਕਹੋ ਜਾਂ 1 ਦਬਾਓ। |

| `askAgain` | ਮਾਫ਼ ਕਰਨਾ। ਦੁਬਾਰਾ ਦੱਸੋ। ਕੀ ਤੁਸੀਂ ਆਪਣੀਆਂ {slot} ਗੋਲੀਆਂ ਲੈ ਲਈਆਂ? |

| `postponeLimit` | ਇਹ ਖੁਰਾਕ ਤਿੰਨ ਵਾਰ ਅੱਗੇ ਪਾਈ ਗਈ ਹੈ। ਮੈਂ ਤੁਹਾਡੀ ਦੇਖਭਾਲ ਟੀਮ ਨੂੰ ਦੱਸ ਰਿਹਾ ਹਾਂ। |
| `nurseComing` | ਕੁਝ ਹੀ ਮਿੰਟਾਂ ਵਿੱਚ ਇੱਕ ਨਰਸ ਤੁਹਾਨੂੰ ਫ਼ੋਨ ਕਰੇਗੀ। |

| `tellingTeam` | ਧੰਨਵਾਦ। ਮੈਂ ਤੁਹਾਡੀ ਦੇਖਭਾਲ ਟੀਮ ਨੂੰ ਦੱਸ ਰਿਹਾ ਹਾਂ। |
