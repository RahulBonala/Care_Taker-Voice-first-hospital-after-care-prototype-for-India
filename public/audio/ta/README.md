# Tamil fallback clips

Used when the browser has no ta-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | வணக்கம் {name}. நான் உங்கள் மருத்துவமனையிலிருந்து கேர் டேக்கர் பேசுகிறேன். |
| `askTaken` | சாப்பிட்டீர்களா? உங்கள் {slot} மாத்திரைகளை எடுத்துக்கொண்டீர்களா? |
| `progress` | இன்று உங்கள் {total} நாள் கோர்ஸில் {n}வது நாள். கோர்ஸை முடிக்கச் சொல்லி உங்கள் டாக்டர் கேட்டிருக்கிறார். |
| `readback` | நீங்கள் {time} மணிக்கு உங்கள் {slot} மாத்திரைகளை எடுத்தீர்கள். சரியா? ஆமாம் என்று சொல்லுங்கள் அல்லது 1 அழுத்துங்கள். |
| `confirmed` | நன்றி. நான் குறித்துக்கொண்டேன். |
| `askAgain` | மன்னிக்கவும். மீண்டும் சொல்லுங்கள். உங்கள் {slot} மாத்திரைகளை எடுத்துக்கொண்டீர்களா? |
| `notTakenOffer` | இப்போது எடுத்துக்கொள்வீர்களா? நான் 30 நிமிடத்தில் மீண்டும் அழைக்கலாம். |
| `takeNow` | தயவுசெய்து இப்போதே எடுத்துக்கொள்ளுங்கள். நான் {minutes} நிமிடத்தில் மீண்டும் அழைப்பேன். |
| `postponeOk` | சரி. நான் {minutes} நிமிடத்தில் மீண்டும் அழைப்பேன். |
| `postponeLimit` | இந்த மாத்திரையை மூன்று முறை தள்ளிவைத்துவிட்டோம். உங்கள் பராமரிப்புக் குழுவிடம் சொல்கிறேன். |
| `nurseComing` | சில நிமிடங்களில் ஒரு நர்ஸ் உங்களை அழைப்பார். |
| `askWhyStopped` | ஏன் நிறுத்தினீர்கள் என்று சொல்ல முடியுமா? |
| `tellingTeam` | நன்றி. உங்கள் பராமரிப்புக் குழுவிடம் சொல்கிறேன். |
| `askCallbackWhen` | நான் எப்போது மீண்டும் அழைக்கட்டும்? |
| `unclear` | மன்னிக்கவும், எனக்குச் சரியாகக் கேட்கவில்லை. உங்கள் {slot} மாத்திரைகளை எடுத்துக்கொண்டீர்களா? |
| `keypad` | தயவுசெய்து கீபேடைப் பயன்படுத்துங்கள். எடுத்திருந்தால் 1 அழுத்துங்கள். பிறகு அழைக்க 2 அழுத்துங்கள். நர்ஸிடம் பேச 3 அழுத்துங்கள். |
| `noKey` | எனக்குப் பதில் கிடைக்கவில்லை. உங்கள் பராமரிப்புக் குழுவிடம் சொல்கிறேன். |
| `goodbye` | உடம்பைப் பார்த்துக்கொள்ளுங்கள். நான் {time} மணிக்கு மீண்டும் அழைப்பேன். |
| `goodbyeDone` | உடம்பைப் பார்த்துக்கொள்ளுங்கள். இது உங்கள் கோர்ஸின் கடைசி மாத்திரை. |
| `optOut` | சரி. அழைப்புகளை நிறுத்துகிறேன். உங்கள் பராமரிப்புக் குழுவுக்குத் தெரிவிக்கப்படும். |
