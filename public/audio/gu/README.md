# Gujarati fallback clips

Used when the browser has no gu-IN voice and no Sarvam key is set. Record each line below as `<lineId>.mp3` in this folder. Lines with {placeholders} are recorded with the most common value, and the screen always shows the exact text.

| lineId | Text |
|---|---|
| `greeting` | નમસ્તે {name}. હું તમારી હોસ્પિટલમાંથી કેર ટેકર બોલું છું. |
| `askTaken` | તમે જમ્યા? તમારી {slot} ગોળીઓ લીધી? |
| `progress` | આજે તમારા {total} દિવસના કોર્સનો {n}મો દિવસ છે. ડૉક્ટરે કોર્સ પૂરો કરવા કહ્યું છે. |
| `readback` | તમે {time} વાગ્યે તમારી {slot} ગોળીઓ લીધી. બરાબર છે? હા કહો અથવા 1 દબાવો. |
| `confirmed` | આભાર. મેં લખી લીધું છે. |
| `askAgain` | માફ કરશો. ફરી કહો. તમારી {slot} ગોળીઓ લીધી? |
| `notTakenOffer` | હમણાં લેશો? હું 30 મિનિટ પછી ફરી ફોન કરી શકું. |
| `takeNow` | કૃપા કરીને હમણાં જ લઈ લો. હું {minutes} મિનિટ પછી ફોન કરીશ. |
| `postponeOk` | સારું. હું {minutes} મિનિટ પછી ફરી ફોન કરીશ. |
| `postponeLimit` | આ ડોઝ ત્રણ વાર પાછળ ગયો છે. હું તમારી સંભાળ ટીમને જણાવું છું. |
| `nurseComing` | થોડી મિનિટોમાં એક નર્સ તમને ફોન કરશે. |
| `askWhyStopped` | તમે કેમ બંધ કર્યું તે કહેશો? |
| `tellingTeam` | આભાર. હું તમારી સંભાળ ટીમને જણાવું છું. |
| `askCallbackWhen` | હું ફરી ક્યારે ફોન કરું? |
| `unclear` | માફ કરશો, બરાબર સંભળાયું નહીં. તમારી {slot} ગોળીઓ લીધી? |
| `keypad` | કૃપા કરીને કીપેડ વાપરો. લીધી હોય તો 1. પછી ફોન માટે 2. નર્સ માટે 3. |
| `noKey` | મને જવાબ મળ્યો નહીં. હું તમારી સંભાળ ટીમને જણાવું છું. |
| `goodbye` | ધ્યાન રાખજો. હું {time} વાગ્યે ફરી ફોન કરીશ. |
| `goodbyeDone` | ધ્યાન રાખજો. આ તમારા કોર્સનો છેલ્લો ડોઝ હતો. |
| `optOut` | સારું. હું ફોન બંધ કરું છું. તમારી સંભાળ ટીમને જણાવવામાં આવશે. |
